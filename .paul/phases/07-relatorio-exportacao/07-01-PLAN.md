<objective>
Seus dados são seus: exportar tudo em formato aberto e fazer um backup que só abre com a senha da pessoa. Esta etapa é só lógica e banco (sem telas, sem arquivos do sistema).
</objective>

<acceptance_criteria>
## AC-1 Exportação JSON
- `exportAll(db)` gera `{ format: "ciclo-livre", version: 1, exportedAt, schema: user_version, profile, logs: { selections, measures, notes, tags, dayTags }, prefs, reminders }`.
- Ordem determinística, só dados da pessoa. A chave do banco nunca entra.

## AC-2 CSV
- Uma linha por dia com registro; colunas: data, depois cada categoria (opções separadas por "; "), medições, tags e nota.
- Escapa aspas, vírgulas e quebras de linha (RFC 4180).
- Neutraliza fórmulas (`=`, `+`, `-`, `@` no início ganham apóstrofo).
- Cabeçalho em pt-BR, UTF-8 com BOM, para abrir certo no Excel e no Sheets.

## AC-3 Backup criptografado
- Envelope `{ format: "ciclo-livre-backup", version: 1, kdf: { name: "scrypt", N, r, p, salt }, cipher: { name: "aes-256-gcm", nonce }, data }`, em base64.
- Usa `@noble/ciphers` e `@noble/hashes` (JS puro e auditadas).
- Senha com pelo menos 8 caracteres. Salt e nonce aleatórios via `expo-crypto`, injetados para dar para testar.
- Senha errada ou arquivo adulterado: erro "Senha incorreta ou arquivo danificado", sem pistas.
- Tempo de derivação medido no S21 FE (meta < 3s); N ajustado se precisar.

## AC-4 Restauração
- `importAll(db, data)` valida o formato e a versão (recusa versão futura) e cada registro (datas, categorias e opções do catálogo, faixas das medições, tamanhos).
- Substitui tudo numa única transação, via `enqueueWrite`; se falhar, nada muda.
- Só queries parametrizadas.
- Ida e volta (exportar, apagar, importar) reproduz o banco igual.

## AC-5 Qualidade
TDD com `node:sqlite`; cobertura de pelo menos 90% em `src/domain/export` e `src/db/export-repo`; tsc; lint; nada do conteúdo vai para o log.
</acceptance_criteria>

<boundaries>
- Sem UI, sem arquivos e sem compartilhamento (07-03). PDF fica no 07-02.
- Sem nuvem própria e sem OAuth: o Drive entra pelo compartilhar e pelo seletor do Android (07-03).
</boundaries>
