<objective>
## Goal
- **Marcar ciclos fora do padrão:** um ciclo completo é marcado quando difere 8 dias ou mais da mediana dos outros ciclos completos recentes. Isso exige pelo menos 3 ciclos de referência. Ciclos implausíveis (fora de 15–90 dias) também ficam marcados, como já são excluídos hoje.
- **Previsão:** os ciclos marcados saem da média. O interruptor "Incluir ciclos fora do padrão nas previsões", no perfil, desligado por padrão, inclui de volta.
- **Comparação com o habitual:** cada ciclo completo diz quantos dias ficou mais curto ou mais longo que o habitual, no histórico da Análise, no PDF e no contexto do chat.

## Purpose
Um ciclo muito diferente (doença, viagem, pós-pílula, registro esquecido) puxa a média e piora as próximas previsões. O Flo marca e exclui esses ciclos; o Ciclo Livre fará o mesmo, de forma transparente e reversível.

## Output
- Função pura `atypicalFlags`.
- Campo de perfil `includeAtypical` (migration v9, backup).
- `CycleRow.atypical` e `CycleRow.diffFromUsual`.
- Interface no histórico, no PDF e no chat.
</objective>

## AC-1: Critério
```gherkin
Given os ciclos 28, 29, 27, 45, 28
Then só o de 45 é fora do padrão (mediana dos outros = 28; diferença 17 ≥ 8)
Given 28, 29, 40 (2 referências por ciclo)
Then nenhum é marcado (poucos dados)
Given um ciclo de 10 ou de 120 dias
Then ele é marcado (implausível)
```

## AC-2: Previsão
```gherkin
Given ciclos 28, 29, 27, 45, 28 e includeAtypical = false
Then a média da previsão usa 28, 29, 27, 28
And com includeAtypical = true usa os cinco (como hoje, menos os implausíveis)
```

## AC-3: Comparação
```gherkin
Given um ciclo completo
Then diffFromUsual = duração − mediana dos outros ciclos completos recentes (null com menos de 2 referências)
And o histórico mostra "N dias mais curto/longo que o normal" quando |N| ≥ 2 e o selo "Fora do padrão" quando marcado
And o PDF e o chat trazem a mesma informação
```

## AC-4: Preferência e backup
```gherkin
Given o interruptor em Dados do ciclo
Then o valor é salvo (migration v9, default 0), vai no backup e backup antigo sem o campo restaura como false
```
