<objective>
## Goal
Fechar a base de privacidade da fase 1:
- **logger seguro:** só aceita nome de evento fixo e metadados numéricos/booleanos; nada de texto livre (nunca carrega conteúdo de registro, nota, chave);
- **aviso médico:** "não é método contraceptivo nem dispositivo médico", visível em Mais (o onboarding da fase 2 reaproveita o texto);
- **apagar todos os dados:** fecha o banco, apaga o arquivo e depois a chave do secure-store, e reabre um banco novo vazio. Confirmação explícita antes.

## Purpose
Princípio "Privacidade por padrão" e LGPD (direito de eliminação). A partir da fase 2 o app grava dados reais; a saída de emergência e a disciplina de log precisam existir antes.
</objective>

<acceptance_criteria>

## AC-1: Logger não carrega texto livre
```gherkin
Given o logger
When chamo logEvent('db_opened', { migrations: 1, encrypted: true })
Then em desenvolvimento sai uma linha com o nome do evento e os metadados
And em produção eventos info não saem
And o tipo só aceita metadados number | boolean (string é erro de compilação, e em runtime é descartada)
And logError(evento, erro) registra só evento e error.name, nunca error.message
```

## AC-2: Apagar tudo remove banco e chave, nessa ordem
```gherkin
Given um banco aberto e uma chave guardada
When eraseAllData roda
Then fecha a conexão, apaga o arquivo do banco e só então apaga a chave
And se apagar o arquivo falhar, a chave é mantida e o erro propaga (evita banco órfão ilegível)
```

## AC-3: Seção de privacidade em Mais
```gherkin
Given a aba Mais
Then vejo o aviso "não é método contraceptivo nem dispositivo médico" e uma explicação de que os dados ficam só no aparelho, criptografados
And o botão "Apagar todos os dados" pede confirmação explícita antes de agir
And depois de apagar, o app continua funcionando com um banco novo
```

## AC-4: No aparelho
```gherkin
Given o dev build no RQCRA00XP8N
When apago todos os dados pela aba Mais
Then o app continua aberto, sem erros no logcat
And o banco existe de novo (recriado) e continua criptografado
```

## AC-5: Qualidade
npm test, tsc e lint passam; nenhum `console.` fora de `src/lib/logger.ts`.
