<objective>
Fechar o registro diário com o que no app de referência é pago: tags sem limite e personalização de categorias, além de navegar entre dias.
</objective>

<acceptance_criteria>
## AC-1: Tags (TDD domínio + banco, migration v4)
- Nome 1–30 caracteres (aparado), sem duplicata ignorando maiúsculas/acentos; ilimitadas.
- Criar, renomear, excluir (remove dos dias); marcar/desmarcar tags num dia.
- Seção "Suas tags" no registro: chips das tags + "Nova tag".

## AC-2: Personalizar categorias (/registro/personalizar)
- Lista das categorias visíveis do modo, cada uma com "Mostrar" (switch) e mover para cima/baixo (botões com nome acessível; sem depender de arrastar).
- Salva em `category_pref`; o registro aplica `orderCategories` (ocultas somem; novas entram no fim).
- "Restaurar padrão".

## AC-3: Outros dias
Registro com "Dia anterior" / "Próximo dia" (não passa de hoje); título com a data por extenso.

## AC-4: Qualidade
Testes (domínio, repo com node:sqlite, telas), tsc, lint, detector; prova no S21 FE.
</acceptance_criteria>
